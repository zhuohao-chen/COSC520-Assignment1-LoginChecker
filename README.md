This project compares five approaches for checking whether a username already exists:
1. Linear Search
2. Binary Search
3. Hash Table
4. Bloom Filter
5. Cuckoo Filter

## Course
COSC 520 - Advanced Algorithms

## Language
Python

## Project Structure

- `src/`: algorithm and data structure implementations
- `tests/`: unit tests
- `benchmark/`: dataset generation and benchmarking
- `data/`: local datasets
- `results/`: experimental results and plots
